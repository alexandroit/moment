# Security Policy

## Supported versions

| Version | Supported |
| :--- | :---: |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Use GitHub private vulnerability reporting for the
[alexandroit/moment repository](https://github.com/alexandroit/moment/security/advisories/new).
Include the affected API, a minimal reproduction, impact, and any proposed mitigation.

Do not disclose an unpatched vulnerability in a public issue. Maintainers will acknowledge a valid
report, investigate it against the current release, and coordinate disclosure after a fix is
available.

## Scope

Security support covers code shipped in the published `@stackline/moment-core` tarball. Development,
documentation, and test dependencies are reviewed during releases but are not installed by package
consumers.
